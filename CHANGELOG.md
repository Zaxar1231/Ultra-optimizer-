# Changelog

## v3.3.0

### Новое
- **Автообновление.** При запуске приложение проверяет последний релиз на GitHub и показывает баннер «Доступна версия». Одна кнопка скачивает новый exe, сверяет SHA-256, подменяет файл и перезапускает приложение. Проверку можно выключить или запустить вручную в «О программе».
- **Работа на любом ПК.** Добавлен манифест: корректно определяется версия Windows, учитывается DPI, используются современные системные диалоги. Приложение нацелено на .NET 4.5, поэтому не просит ставить новый .NET. TLS 1.2 включается принудительно.
- Запускается только один экземпляр: повторный запуск разворачивает уже открытое окно.
- Ошибки больше не роняют приложение: показывается сообщение, подробности пишутся в `crash.log`.
- Распаковка скриптов не падает, если файл занят: неизменённые файлы не перезаписываются.
- В CI добавлен сквозной тест автообновления на Windows: скачивание релиза, проверка SHA-256 и подмена exe.
- В README добавлена галерея всех экранов в светлой и тёмной темах, скриншоты есть и в описании релиза.

> Версия 3.2.0 ещё не умеет обновляться сама, поэтому 3.3.0 нужно один раз скачать вручную. Дальше обновления приходят автоматически.

## v3.2.0

### Новое
- **Приложение в стиле Material Design 3.** `UltimateOptimizer.exe` теперь полноценное окно вместо консольного меню. В нём есть навигационная панель с FAB-кнопкой, карточки с железом ПК, переключатели опций, диалоги подтверждения, snackbar, линейный прогресс, светлая и тёмная темы (по умолчанию как в Windows).
- Скрипты работают без окна консоли, вывод идёт в «Журнал» с иконками шагов, успехов и предупреждений. Журнал можно скопировать.
- На главной видны процессор, видеокарта, память (одно- или двухканальный режим), тип диска, версия Windows, тип устройства, а также подсказки по апгрейду.
- Рискованные опции (VBS и Spectre/Meltdown) включаются переключателями. Для этого у скрипта появились ключи `-DisableVBS` и `-DisableMitigations`.
- `Win11-Repair.ps1 -Action Restore|Undo|Repair|Network|All` запускает нужный пункт без меню.
- В CI каждый экран рендерится в обеих темах, скриншоты прикладываются к сборке.

## v3.1.0

### Новое
- **`UltimateOptimizer.exe`** — один файл со всеми скриптами внутри и меню: оптимизация, откат, починка, отчёт о ПК, optimizerDuck. Сам запрашивает права администратора.
- **optimizerDuck** — `Get-OptimizerDuck.ps1` / `5-Get-OptimizerDuck.bat` качают последний релиз [itsfatduck/optimizerDuck](https://github.com/itsfatduck/optimizerDuck) под x64 или ARM64 и сверяют SHA-256. Основной оптимизатор тоже скачивает его в `C:\Tools\optimizerDuck` (отключается ключом `-NoDuck`).
- Сборка и релизы через GitHub Actions, проверка скриптов PSScriptAnalyzer.

### Исправлено
- `Ultimate-Optimizer.ps1`: winget-код «уже установлено» (`0x8A150061`) больше не считается ошибкой.
- `Ultimate-Optimizer.ps1`: если не удалось прочитать `disablelastaccess`, откат больше не вызывает `fsutil` с пустым значением.
- `Ultimate-Optimizer.ps1`: понятное сообщение для Windows 7/8.1 и предупреждение для 32-битной системы.
- `PC-Info-Mail.ps1`: убран зашитый e-mail автора — адреса спрашиваются при первом запуске и запоминаются локально.
- `PC-Info-Mail.ps1`: Secure Boot на компьютерах с Legacy BIOS показывается как `n/a` вместо ошибки.
- `Win11-Repair.ps1`: при перерегистрации приложений пропускаются пакеты без манифеста; `chkdsk /scan` без лишнего `echo Y`; в подсказке восстановления указана точка «Before Ultimate-Optimizer».
