# Changelog

## v3.6.2

### Исправлено
- Оптимизация больше не выглядит зависшей на шаге «Очистка». Очистка хранилища компонентов (DISM) на ПК с большим числом обновлений может молча идти 20–60 минут. Теперь в журнал каждые 30 секунд пишется, сколько прошло. Через 15 минут очистка останавливается: Windows доделает её сама во время обслуживания. Для TRIM лимит 5 минут.
- Временные файлы, занятые другими программами, пропускаются без ошибок.
- Приложение не остаётся в состоянии «Выполняется», если установщик из шага «Программы» запустил свою программу и та держит вывод скрипта открытым.

## v3.6.1

### Исправлено
- Автообновление больше не ломается, когда исчерпан лимит GitHub API (60 запросов в час на IP, часто бывает у провайдеров с общим IP). В этом случае версия определяется через страницу последнего релиза, а файлы и контрольные суммы скачиваются по прямым ссылкам.

## v3.6.0

### Новое
- **Раздел «Сеть и задержка».**
  - Пинг до роутера, Cloudflare, Google, Яндекса и Quad9: средняя задержка, джиттер, потери и разница с прошлой проверкой. Если пинг до роутера высокий, приложение подсказывает про Wi-Fi.
  - Тест DNS прямыми UDP-запросами: Cloudflare, Google, Яндекс, Quad9, AdGuard и DNS провайдера. Самый быстрый ставится одной кнопкой, старый DNS сохраняется в бэкап.
- **Новая группа твиков «Сеть и задержка»** (70 твиков всего):
  - без алгоритма Нейгла и отложенного ACK;
  - сетевая карта в режиме низкой задержки: без Interrupt Moderation, Flow Control, LSO и Packet Coalescing;
  - Wi-Fi без фонового роуминга;
  - настройка стека TCP;
  - QoS не резервирует канал.
- **Менеджер автозагрузки**: реестр и папки «Автозагрузка», иконки, издатель, команда, переход к файлу. Включение и выключение совместимо с диспетчером задач.
- **Менеджер планировщика задач**: поиск, фильтр «Сторонние / Microsoft / Все», следующий запуск, автор, команда, включение и выключение.
- **Менеджер приложений**: понятные названия, отметка рекомендуемых, удаление разом. Удалённое записывается в бэкап, встроенные приложения возвращаются через «Откатить всё».
- В `Ultimate-Optimizer.ps1` добавлены ключи `-SetDns` и `-RemoveApps`. «Откатить всё» восстанавливает DNS, автонастройку TCP и RSS.

## v3.5.0

### Новое
- **Твики optimizerDuck теперь встроены.** Само приложение optimizerDuck больше не скачивается. Твиков стало 65 вместо 47:
  - USB-устройства без энергосбережения (с точным откатом), MMCSS без «ленивого» режима;
  - NVIDIA: без динамических и асинхронных P-state; AMD: без ASPM, power gating и clock gating; Intel: без асинхронных flip и адаптивного V-Sync;
  - быстрый повтор клавиш, без залипания клавиш, чистое меню «Пуск»;
  - поиск без Bing и Cortana, без фоновых логгеров AutoLogger, по желанию без геолокации и «Поиска устройства»;
  - долгая пауза обновлений, WebDAV без лимита 50 МБ;
  - рискованный пункт «Службы в ручной запуск» (список WinUtil), по умолчанию выключен;
  - телеметрия, реклама, ИИ (Recall, Click to Do), виджеты и история действий закрыты полнее.
- **Экран «Настройка Windows».** Около 40 переключателей, которые применяются сразу и показывают текущее состояние: значки рабочего стола, панель задач, Проводник (расширения, скрытые файлы, классическое меню), тёмная тема, уведомления, журнал буфера обмена, NumLock, длинные пути, режим разработчика, Game Bar, оптимизация во весь экран, HAGS, акселерация мыши, индикатор DLSS. Есть кнопка «Перезапустить Проводник».
- **«Инструменты» → «Очистка»** вместо карточки optimizerDuck: временные файлы, компоненты обновлений, TRIM и DNS одной кнопкой, без создания точки восстановления.
- В `Ultimate-Optimizer.ps1` добавлен ключ `-NoRestorePoint`. Ключ `-NoDuck` по-прежнему принимается, но больше ничего не делает.

## v3.4.0

### Новое
- **Профили одной кнопкой**: «Игры», «Ноутбук», «Работа и учёба», «Слабый ПК».
- **Выбор отдельных твиков.** Оптимизатор разбит на 47 твиков в 9 группах, у каждого есть описание и свой переключатель. Группы раскрываются и показывают счётчик «N из M». Если поменять переключатель, набор становится «своим». Выбор запоминается.
- **Замер «до» и «после».** Новый экран с 8 показателями: задержка отклика (медиана и 99-й перцентиль), фоновая загрузка CPU, занятая память, процессы, службы, время загрузки Windows, автозагрузка, свободное место. Разница показывается в процентах. Замер «до» делается сам перед первой оптимизацией, «после» — при первом запуске после перезагрузки.
- `Ultimate-Optimizer.ps1 -Only id1,id2,...` применяет только выбранные твики. Без `-Only` всё работает как раньше.
- При сборке проверяется, что ID твиков в `tweaks.json` и в скрипте совпадают.
- В CI добавлен настоящий замер на Windows.

## v3.3.0

### Новое
- **Автообновление.** При запуске приложение проверяет последний релиз на GitHub и показывает баннер «Доступна версия». Одна кнопка скачивает новый exe, сверяет SHA-256, подменяет файл и перезапускает приложение. Проверку можно выключить или запустить вручную в «О программе».
- **Работа на любом ПК.** Добавлен манифест: корректно определяется версия Windows, учитывается DPI, используются современные системные диалоги. Приложение нацелено на .NET 4.5, поэтому не просит ставить новый .NET. TLS 1.2 включается принудительно.
- Запускается только один экземпляр: повторный запуск разворачивает уже открытое окно.
- Ошибки больше не роняют приложение: показывается сообщение, подробности пишутся в `crash.log`.
- Распаковка скриптов не падает, если файл занят: неизменённые файлы не перезаписываются.
- В CI добавлен сквозной тест автообновления на Windows: скачивание релиза, проверка SHA-256 и подмена exe.
- В README добавлена галерея всех экранов в светлой и тёмной темах, скриншоты есть и в описании релиза.

> Версия 3.2.0 ещё не умеет обновляться сама, поэтому 3.3.0 нужно один раз скачать вручную. Дальше обновления приходят автоматически.

## v3.2.0

### Новое
- **Приложение в стиле Material Design 3.** `UltimateOptimizer.exe` теперь полноценное окно вместо консольного меню. В нём есть навигационная панель с FAB-кнопкой, карточки с железом ПК, переключатели опций, диалоги подтверждения, snackbar, линейный прогресс, светлая и тёмная темы (по умолчанию как в Windows).
- Скрипты работают без окна консоли, вывод идёт в «Журнал» с иконками шагов, успехов и предупреждений. Журнал можно скопировать.
- На главной видны процессор, видеокарта, память (одно- или двухканальный режим), тип диска, версия Windows, тип устройства, а также подсказки по апгрейду.
- Рискованные опции (VBS и Spectre/Meltdown) включаются переключателями. Для этого у скрипта появились ключи `-DisableVBS` и `-DisableMitigations`.
- `Win11-Repair.ps1 -Action Restore|Undo|Repair|Network|All` запускает нужный пункт без меню.
- В CI каждый экран рендерится в обеих темах, скриншоты прикладываются к сборке.

## v3.1.0

### Новое
- **`UltimateOptimizer.exe`** — один файл со всеми скриптами внутри и меню: оптимизация, откат, починка, отчёт о ПК, optimizerDuck. Сам запрашивает права администратора.
- **optimizerDuck** — `Get-OptimizerDuck.ps1` / `5-Get-OptimizerDuck.bat` качают последний релиз [itsfatduck/optimizerDuck](https://github.com/itsfatduck/optimizerDuck) под x64 или ARM64 и сверяют SHA-256. Основной оптимизатор тоже скачивает его в `C:\Tools\optimizerDuck` (отключается ключом `-NoDuck`).
- Сборка и релизы через GitHub Actions, проверка скриптов PSScriptAnalyzer.

### Исправлено
- `Ultimate-Optimizer.ps1`: winget-код «уже установлено» (`0x8A150061`) больше не считается ошибкой.
- `Ultimate-Optimizer.ps1`: если не удалось прочитать `disablelastaccess`, откат больше не вызывает `fsutil` с пустым значением.
- `Ultimate-Optimizer.ps1`: понятное сообщение для Windows 7/8.1 и предупреждение для 32-битной системы.
- `PC-Info-Mail.ps1`: убран зашитый e-mail автора — адреса спрашиваются при первом запуске и запоминаются локально.
- `PC-Info-Mail.ps1`: Secure Boot на компьютерах с Legacy BIOS показывается как `n/a` вместо ошибки.
- `Win11-Repair.ps1`: при перерегистрации приложений пропускаются пакеты без манифеста; `chkdsk /scan` без лишнего `echo Y`; в подсказке восстановления указана точка «Before Ultimate-Optimizer».
